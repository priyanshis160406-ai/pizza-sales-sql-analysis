Pizza Sales Analysis Using SQL

Project Overview

This project analyzes pizza sales data using SQL queries to understand sales performance and customer ordering patterns.

Objectives

- Analyze overall pizza sales.
- Identify popular pizza products.
- Understand order trends.
- Explore sales performance using SQL queries.

Tools Used

- SQL
- Relational Database

SQL Skills Demonstrated

- Data aggregation
- Filtering and sorting
- GROUP BY and ORDER BY
- Aggregate functions such as SUM, COUNT, and AVG

Business Questions

- What are the total sales and total number of orders?
- Which pizzas are the most popular?
- Which pizza categories perform best?
- What sales patterns can be identified from the data?

Project Files

- SQL query file: Contains queries used for pizza sales analysis.

Conclusion

This project demonstrates the use of SQL to explore sales data and answer business questions through data analysis.# pizza-sales-sql-analysis
